# Учёт оборудования — «Бархатные сезоны»

Дипломный проект веб-системы материального учёта оборудования для города-отеля «Бархатные сезоны». Система предназначена для ведения реестра, отслеживания местонахождения и технического состояния оборудования, ответственности сотрудников и истории изменений.

## Состав проекта

| Каталог                      | Содержимое                                                           |
| ---------------------------- | -------------------------------------------------------------------- |
| [backend](backend/README.md) | API на NestJS и TypeORM, подключение к MariaDB, автоматические тесты |
| [docs](docs/README.md)       | Кликабельный макет интерфейса с демонстрационными данными            |
| [database](database/)        | SQL-схема MariaDB и скрипт подготовки тестовой базы                  |
| [modeling](modeling/)        | Модели предметной области, диаграммы и описания таблиц               |

## Текущее состояние

В бэкенде реализованы получение сведений о приложении и чтение справочника технических состояний из MariaDB. Для них есть проверки контроллера, HTTP-маршрутов и интеграции с тестовой базой. Авторизация и серверные операции с оборудованием находятся в разработке.

Макет показывает реестр и карточки оборудования, перемещения, передачу ответственности, работу с комплектующими и инвентаризационные проверки. Он использует вымышленные данные и работает отдельно от API.

Стек бэкенда: TypeScript, NestJS 11, TypeORM 0.3, MariaDB. Макет написан на HTML, CSS и JavaScript.

## Запуск

- Для просмотра макета откройте [docs/index.html](docs/index.html) в браузере.
- Для запуска API подготовьте MariaDB и локальные настройки по [инструкции бэкенда](backend/README.md).
- Команды сборки и тестирования приведены в [разделе проверок](backend/README.md#тесты).

SQL-скрипты начального создания и обновления схемы применяются по порядку и рассчитаны на однократное выполнение. Порядок подготовки базы описан в [документации бэкенда](backend/README.md#подготовка-базы-данных).
