# Макет интерфейса

Статичный фронтенд-макет системы учета оборудования. Настоящий backend и подключение к MariaDB не используются. Изменения карточек, перемещения, установок и проверок работают в браузере на локальных демонстрационных данных; они сохраняются в `localStorage` этого браузера.

Визуальная тема основана на предоставленном логотипе: белый верхний блок, голубая навигация, синие акценты и плотная геометричная типографика в заголовках. Для заголовков используется Montserrat, для основного текста — Roboto; при отсутствии интернета включатся системные шрифты.

## Запуск

Откройте `index.html` в браузере. Установка Node.js, Docker и дополнительных пакетов не нужна.

Для просмотра на GitHub можно включить GitHub Pages в настройках репозитория и выбрать публикацию из ветки `main`, папка `/docs`. После публикации GitHub предоставит ссылку на работающий интерфейс. Чтобы изменения попали в репозиторий, нужно добавить эту папку в коммит и отправить его на GitHub.

## Демонстрация ролей

В правом верхнем углу можно переключиться между профилем МОЛ и профилем руководства. МОЛ может просматривать общий реестр, но редактировать карточки только закрепленного за ним оборудования. Руководство может редактировать все записи. Это выбранный сценарий для показа; окончательная матрица прав должна быть подтверждена организацией.

## Данные и локации

Сотрудники, инвентарные номера, серийные номера и записи об оборудовании в макете придуманы. Из переданной Excel-таблицы использованы только структура колонок и характер заполнения; реальные имена и номера не перенесены. Названия кварталов, участков, корпусов, секций и помещений в макете демонстрационные; почтовые адреса не показываются.

Основные функции макета: реестр и фильтры, карточка оборудования, статусы, перемещения, смена МОЛ, установка/снятие комплектующих, журнал событий, инвентаризационные проверки, справочники, список сотрудников, предварительная форма импорта и выгрузка CSV.
