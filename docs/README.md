# Макет интерфейса

Кликабельный макет системы материального учёта оборудования для города-отеля «Бархатные сезоны». Используется для демонстрации экранов и обсуждения рабочих сценариев.

## Просмотр

Откройте [index.html](index.html) в браузере.

## Сценарии

- Поиск оборудования и фильтрация реестра.
- Просмотр и редактирование карточки оборудования.
- Изменение состояния, перемещение, передача ответственности и списание.
- Учёт комплектующих, их установка и снятие.
- Просмотр истории изменений.
- Проведение демонстрационных инвентаризационных проверок.
- Работа со списком сотрудников и справочниками.
- Выгрузка реестра и журнала событий в CSV.

Форма импорта показывает выбор файла и переход к предварительной проверке. Обработка содержимого файла пока не реализована.

## Профили пользователей

Переключатель в правом верхнем углу меняет профиль, от которого показывается интерфейс:

| Профиль                              | Доступ в макете                                              |
| ------------------------------------ | ------------------------------------------------------------ |
| МОЛ — материально ответственное лицо | Просмотр всего реестра, изменение закреплённого оборудования |
| Руководство                          | Просмотр и изменение всех записей                            |

Переключение профиля имитирует права доступа. Окончательная матрица прав для рабочей системы ещё не определена.

## Демонстрационные данные

В макете используются вымышленные записи об оборудовании, сотрудниках и локациях. Изменения оборудования сохраняются в localStorage браузера и доступны при повторном открытии макета в том же окружении.

Макет работает отдельно от [бэкенда](../backend/README.md). Данные между ними не передаются.
